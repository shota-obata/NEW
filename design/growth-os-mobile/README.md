# Growth OS Mobile — 設計ハンドオフ

AI,re 社内育成OSのモバイル設計です。**プロダクションコードではありません。** リポジトリ直下の実装（`home-v56.js` ほか）を、この設計に合わせて作り替えるための参照資料です。

`Growth OS Mobile.dc.html` はソースです。**色・字寸・余白・コピーの正確な値はここから読めます。** ブラウザで開くと全画面を触れます（`ios-frame.jsx` / `support.js` はプレビュー用の枠と実行環境で、実装には不要です）。

## 実装で外せない前提

1. **認証は「端末登録 ＋ 個人ID ＋ 4桁PIN」。** 未登録の端末ではPINの入力欄まで到達しません。
2. **可視領域はUIで隠さない。** `PERMISSIONS.md` の表がそのまま `RLS.md` のポリシーです。画面側の出し分けはレスポンスを変えません。
3. **監査ログの例外は1つだけ**（運営者の「閲覧」）。周知・在籍者全員の同意・施行日の3つが揃うまで開きません。
4. **未同意のユーザーは本体に入れません。** 抜け道は作りません。
5. **時間外・定休日に通知は飛びません。** 火曜は定休日です。
6. **退職・削除で記録は消えません。** 氏名を `Other` に置換して残します。

## 原本の所在

条文の原本は、デザインプロジェクト側の `就業規則 追加条文 草案.dc.html`（印刷用）です。印刷シェル `doc-page.js` に依存するためリポジトリには取り込んでいません。**条文を直すときは原本を直し、`handoff/WORK_RULES_ARTICLES.md` を写し直してください。** PDF が必要なときも原本から書き出します。

同様に、単体で全画面を触れる `Growth OS Mobile (standalone).html` もデザイン側で再生成するため、ここには含めていません。
